    摄影基础概念学习笔记

    前言

    为什么开始学习摄影

    喜欢逛漫展，手机拍照太垃圾了，想系统性学习摄影，就入坑学习了

    这篇文章主要解决什么问题

    快速建立基础概念，作为个人的笔记

    学习摄影需要先建立的几个认知

    • 相机不是决定照片好坏的唯一因素
    • 摄影本质是控制光线
    • 参数服务于画面，而不是为了调参数而调参数

    一、摄影的核心：光

    1. 什么是曝光

    曝光指的是传感器接收到光线并形成图像的过程。

    接收的光太多，画面会过曝，高光部分细节丢失、一片白；接收的光太少，画面会欠曝，暗部细节丢失、一片黑。

    曝光的目标不是“足够亮”，而是“亮度符合画面想表达的氛围”。有时故意欠曝拍剪影，有时故意过曝拍高调，都是合理的创作选择。

    决定曝光多少的，就是下面的曝光三要素。

    2. 曝光三要素

    光圈 Aperture

    控制镜头进光孔的大小，用 F 值表示，F 值越小光圈越大、进光越多、背景越容易虚化。

    快门 Shutter Speed

    控制快门开启的时长，快门越慢进光时间越长、画面越亮，但也越容易拍出运动模糊。

    ISO 感光度

    控制传感器信号的放大程度，ISO 越高画面越亮，但噪点也会越明显。

    3. 曝光三要素之间的关系

    4. 什么是曝光补偿

    相机自动测光给出的曝光值并不总是符合预期，比如拍雪景或逆光人像时，相机很容易把画面拍暗。

    这时可以手动叠加曝光补偿（EV）：

    +EV ：主动让画面更亮（适合雪景、白色背景）
-EV ：主动让画面更暗（适合黑色背景、想要更有氛围感）

    曝光补偿不改变光圈/快门/ISO 的搭配逻辑，只是在相机测光结果的基础上再手动微调亮度。

    5. 什么是测光

    测光决定了相机会参考画面中哪个区域的亮度来计算曝光。

    平均测光

    参考整个画面的平均亮度，适合光线均匀的场景。

    中央重点测光

    以画面中央为主，兑顾四周，适合主体大致居中的拍摄。

    点测光

    只参考对焦点周围小范围的亮度，适合逆光或高对比光比场景。

    多重测光

    将画面分区域综合计算，是最常用的默认测光模式，适合大多数日常场景。

    二、光学基础概念

    1. 焦距是什么

    焦距是镜头光学中心到成像面（传感器）的距离，单位是 mm。

    焦距越短，拍到的范围越宽（广角）；焦距越长，拍到的范围越窄、主体越被拉近（长焦）。

    2. 视角是什么

    视角指镜头能够拍摄到的画面范围大小，由焦距和传感器尺寸共同决定。

    同样焦距下，传感器越大，视角越宽；传感器越小，视角越窄（相当于被“裁剪”了一部分画面）。

    3. 景深是什么

    景深指对焦点前后能保持清晰的范围。

    景深浅（小）：对焦点前后很快就模糊，常用于人像背景虚化。

    景深深（大）：对焦点前后大范围都清晰，常用于风景、建筑、合影。

    4. 虚化和什么有关

    光圈大小

    光圈越大（F 值越小），景深越浅，越容易虚化。

    焦距长短

    焦距越长，景深越浅，虚化越明显（同样光圈下，85mm 比 35mm 更容易虚化）。

    拍摄距离

    离主体越近，景深越浅；离主体越远，景深越深。

    传感器画幅

    画幅越大，同样构图下景深越浅（全画幅比 APS-C 更容易虚化）。

    5. 等效焦距是什么

    不同画幅的传感器大小不同，为了能在不同画幅之间比较视角，引入了“等效焦距”概念：把实际焦距换算成对应全画幅相机下的视角。

    等效焦距 ≈ 实际焦距 × 裁剪系数
APS-C 裁剪系数约为 1.5

    例如 APS-C 机身上的 35mm 镜头，等效焦距约为 50mm。

    6. 安全快门是什么

    安全快门是为了避免手持拍摄时因手抖导致照片模糊的经验公式：

    安全快门 ≈ 1 / 等效焦距

    例如 50mm 镜头安全快门大约是 1/50s，85mm 镜头大约是 1/85s。实际拍摄时可以向上取一档更稳。具体可参考下一篇关于快门与 ISO 的实拍应用。

    三、镜头基础

    1. 镜头的基本参数怎么看

    例如：FE 24-70mm F2.8 GM

    FE      — 卡口（适用机身系统，索尼全画幅卡口）
24-70mm — 焦段范围（变焦镜头，从广角到中长焦）
F2.8    — 最大光圈（数值越小光圈越大）
GM      — 品牌高端系列标识

    看镜头参数时，重点关注焦段范围和最大光圈这两项，它们决定了能拍什么、能不能拍出虚化。

    2. 镜头分类

    定焦镜头

    • 优点：最大光圈大、成像更锐利、体积相对轻巧
    • 缺点：焦段固定，取景需要用脚移动
    • 适合场景：人像、弱光环境、追求极致虚化和画质

    变焦镜头

    • 优点：一支镜头覆盖多个焦段，出门方便、适应性强
    • 缺点：最大光圈通常不如定焦镜头大，体积和重量也更大
    • 适合场景：旅行、日常记录、不确定拍摄距离的场合

    3. 按焦段分类

    超广角镜头

    焦距大约 16mm 以下，视角极宽，常用于建筑、星空、室内狭窄空间。

    广角镜头

    焦距大约 16-35mm，适合风景、建筑、环境人像。

    标准镜头

    焦距大约 35-50mm，接近人眼视角，适合日常、人文、细坡。

    中长焦镜头

    焦距大约 70-135mm，适合人像、人像特写。

    长焦镜头

    焦距 135mm 以上，适合鸟类、体育、舞台等远距离拍摄。

    4. 常见焦段的使用场景

    16mm / 20mm：风景、建筑、空间感

    能容纳更宽阔的场景，适合拍摄大场面的自然风光和建筑内部空间，但边缘容易产生透视变形。

    24mm / 28mm：街拍、旅行、环境人像

    视角仍然偏宽，但变形较小，适合一边交代环境一边交代人物的旅行记录。

    35mm：人文、日常记录

    接近人眼视角，真实自然，是很多人文摄影师的首选焦段。

    50mm：标准视角、人像、静物

    又称“标准焦”，留一定空间给背景，同时也能拍出舒服的人像虚化。

    85mm：人像

    压缩感强，背景虚化明显，是经典的人像焦段。

    70-200mm：人像、活动、远距离拍摄

    可以在不打扰主体的情况下远距离拍摄，常用于演出、演讲、体育等不便靠近的场合。

    5. 光圈大小对镜头的影响

    同一支镜头，最大光圈越大，造价通常越高，但弱光环境下的可用性和虚化能力也越强。

    F1.4 / F1.8 / F2.8 / F4 的区别

    F1.4  — 最大光圈，虚化最强，但景深极浅，对对焦精度要求高
 F1.8  — 性价比高，虚化与容错率平衡，常见于平价定焦镜头
F2.8  — 专业变焦镜头常见规格，兼顾中域虚化与多人合照需求
F4    — 体积重量更轻，适合旅行和日常轻便携带

    四、相机基础

    1. 相机的基本结构

    相机的核心部件大致包括：镜头（负责成像）、机身内的传感器（负责接收光信号）、快门/快门帘（控制曝光时间）、图像处理器（把信号转换为图片）以及取景器/屏幕（用于构图和回放）。

    均无反光相机去掉了传统单反的光学取景结构，直接用传感器实时成像到电子取景器，体积更小、对焦速度也更快。

    2. 画幅是什么

    画幅指传感器的实际物理尺寸。传感器越大，单个像素能接收到的光信息越多，递带影响画质、噪点控制和景深表现。

    全画幅

    尺寸与传统 35mm 胶卷相同（36x24mm），高感、景深控制能力最强，价格也最高。

    APS-C 画幅

    比全画幅小（约 23.5x15.6mm），机身和镜头更轻巧，性价比高，是很多日系机型的主力画幅。

    M43 画幅

    传感器更小（17.3x13mm），机身和镜头群更小巧轻便，典型代表是奇异、松下。

    手机传感器

    尺寸最小，依靠计算摄影弥补硬件上的差距，日常方便但弱光、虚化能力有限。

    3. 不同画幅的区别

    视角区别

    同一支镜头安装在不同画幅机身上，画幅越小视角越窄（相当于被裁剪）。

    景深区别

    同样构图下，画幅越大景深越浅，越容易拍出虚化。

    高感区别

    画幅越大，同像素数下单像素面积越大，高 ISO 下噪点控制通常更好。

    体积和价格区别

    画幅越大，机身和配套镜头通常越大越重越贵。

    4. 像素是不是越高越好

    不是。同样画幅下，像素越高单像素面积越小，高感和完工发色可能反而下降。对大多数人来说，2000-3000 万像素已经足够应付日常拍摄和打印，传感器面积、信号处理算法往往比像素数更影响画质。

    5. RAW 和 JPG 的区别

    RAW 是传感器的原始数据，保留了最完整的信息，方便后期调整曝光、白平衡和色彩，但文件体积大、需要后期软件处理。

    JPG 是相机内部已经压缩处理过的图片，文件小、可以直接使用，但后期可调整空间有限。

    日常随拍可以只开 JPG，重要场合建议 RAW+JPG 同时记录。

    6. 防抖是什么

    防抖用于抑制手抖导致的画面模糊，尤其在慢快门下效果明显。

    机身防抖

    IBIS，传感器直接在机身内部反向移动补偿抖动，对所有镜头都有效果。

    镜头防抖

    OSS/VC 等，在镜头内部用浮动镜片补偿抖动，常与机身防抖协同工作。

    电子防抖

    通过裁剪画面边缘并算法补偿来稳定画面，多用于视频拍摄，会损失一部分视角。

    五、相机挡位

    1. Auto 自动挡

    2. P 档：程序自动曝光

    3. A / Av 档：光圈优先

    全程为光圈优先挡位，光圈是你手动来控制的

    静物/人像

    背景虚化效果

    4. S / Tv 档：快门优先

    能 调整快门/感光度，光圈数值自动调整，

    满足于日常风光/运动

    快门速度快速抓拍是，决胜时刻！

    5. M 档：手动曝光

    全部可调整，曝光补充无效

    六、对焦基础

    1. 什么是对焦

    对焦是让镜头对主体成像清晰的过程。对焦不准时，即使曝光、构图都完美，照片也会因为模糊而不可用。

    2. 单次对焦 AF-S

    对焦完成后锁定，不会跟随主体移动而重新对焦，适合静止主体，如风景、建筑、合影。

    3. 连续对焦 AF-C

    只要快门半按，相机会持续跟随移动中的主体调整对焦，适合人像、宠物、运动等会移动的主体。

    4. 手动对焦 MF

    完全由人手动转动对焦环确定对焦点，适用于自动对焦容易误判的场景，如隔着栏杆拍摄、微距、低对比度环境。

    5. 对焦区域

    广域

    对焦点铺满整个取景框，相机自动判断主体，适合不确定主体会出现在哪里的随拍。

    区

    在一块较大区域内选择对焦，介于广域和中心之间，适合主体在局部范围内移动的场景。

    中心

    只用取景框中央的单一点对焦，精准但需要先构图再对焦，适合主体大致居中的拍摄。

    灵活点

    可以手动将对焦点移动到取景框内任意位置，适合需要精确控制对焦点位置的构图，如人像对焦到眼睛。

    追踪对焦

    选定主体后，对焦框会跟随主体在画面中移动而自动移动，适合拍摄不规则运动的主体。

    6. 人眼识别 / 动物识别 / 物体识别

    现代相机可以自动识别人脸、人眼（甚至左右眼）、常见动物（猫、狗、鸟）以及车辆、火车等物体，开启后会优先对焦这些目标，大大降低人像、宠物拍摄时的脱焦概率。

    七、白平衡与色彩

    1. 白平衡是什么

    白平衡用于纠正不同光源下的颜色偏差，让白色真正看起来是白色，从而保证整张照片的色彩准确。

    2. 色温是什么

    色温以开尔文（K）为单位，数值越低画面越偏暖（橙黄），数值越高画面越偏冷（蓝），与日常直觉恰好相反。

    2000-3000K — 烛光、钨丝灯，偏暖橙
5500K       — 日光，基准中性
8000-10000K — 阴天、阴影，偏冷蓝

    3. 自动白平衡是否可靠

    大多数日常场景下 AWB 足够准确，但在混合光源（如室内暗黄灯 + 窗外日光）或纯色背景下容易判断错误，需要手动预设或自定义白平衡来修正。

    4. 色彩风格 / 创意外观

    相机内置的色彩预设（如鲜艳、人像、复古胶卷）会在 JPG 直出时影响饱和度、对比度和色调倾向，拍 RAW 时这些风格只会作为预览参考，不影响原始数据。

    5. 为什么不同品牌照片颜色不一样

    不同品牌对自动白平衡、测光算法、高光/暗部回收风格有各自的调教取向（如某些品牌偏暖、某些偏冷），这也是很多人选特定品牌的原因之一。

    八、实际拍摄时怎么思考

    1. 拍摄前先判断光线

    先看光的方向（顺光/侧光/逆光）、强弱和色温，再想参数。光线决定了一张照片的上限，参数只能在当前光线下调整曝光关系。

    2. 决定想要的画面效果

    想要背景虚化

    优先开大光圈（小 F 值），搭配长焦、靠近拍摄距离。

    想要画面清晰

    收小光圈（大 F 值），确保前后景都在景深范围内。

    想要冻结动作

    提高快门速度，优先保证快门够快再调光圈和 ISO。

    想要拍出运动轨迹

    主动降低快门速度，搭配三脚架或稳定机体。

    3. 再决定参数

    根据上面两步确定的优先项（光圈/快门/ISO 中先保证哪个），选择对应的拍摄档位（A / S / M），剩下的参数交给相机自动计算或微调。

    4. 最后检查照片

    是否曝光正常

    直方图是否严重偏向一侧，高光是否过曝、暗部是否丢细节。

    是否对焦准确

    放大图像确认主体眼睛/关键部位是否锐利。

    是否构图干净

    检查地平线是否歪、主体位置是否合理。

    是否有多余元素

    检查背景中是否有干扰视线的杂物、人物或光斑。
